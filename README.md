# Agro Forte - Futuro Sustentável 🌱

O **Agro Forte** é um site interativo desenvolvido como parte do [Programa Agrinho](https://www.sistemafaep.org.br/agrinho/), com o objetivo de conscientizar e engajar a comunidade sobre a importância de construir um futuro sustentável através da inovação, produção responsável e preservação ambiental. O projeto foca no equilíbrio essencial entre o desenvolvimento do campo e a proteção da natureza.

## 🚀 Funcionalidades

- **Design Responsivo:** Interface moderna que se adapta perfeitamente a computadores, tablets e smartphones.
- **Modo Escuro (Dark Mode):** Alternância de visualização para maior conforto visual utilizando uma estilização otimizada.
- **Pilares Informativos:** Seções dedicadas que explicam de forma clara as bases do projeto: Sustentabilidade, Tecnologia e Meio Ambiente.

## 📐 Pilares do Projeto

* **🌱 Sustentabilidade:** Práticas agrícolas focadas na preservação a longo prazo de todos os recursos naturais.
* **🚜 Tecnologia:** Aplicação de agricultura de precisão e inovações que otimizam a produtividade no campo.
* **🌎 Meio Ambiente:** Fortalecimento de métodos de produção agrícola que atuam em perfeito equilíbrio com a natureza.

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído utilizando as seguintes tecnologias web:

* **HTML5:** Estruturação semântica de todo o conteúdo da página.
* **CSS3:** Estilização visual personalizada e lógica para o Modo Escuro.
* **JavaScript:** Programação dos recursos interativos e dinâmica de alternância do tema visual.

## 📁 Estrutura de Arquivos

```text
├── index.html       # Página principal e estrutura do conteúdo
├── css/             # Arquivos de estilização visual (CSS)
└── js/              # Scripts de interatividade e comportamento da página
```

## 💻 Como Executar o Projeto

1. **Clonar o Repositório:**
   ```bash
   git clone https://github.com
   ```
2. **Navegar até a Pasta:**
   ```bash
   cd projeto-agrinho
   ```
3. **Abrir no Navegador:**
   Abra o arquivo `index.html` diretamente em seu navegador web de preferência ou utilize uma extensão como o *Live Server* no VS Code.
